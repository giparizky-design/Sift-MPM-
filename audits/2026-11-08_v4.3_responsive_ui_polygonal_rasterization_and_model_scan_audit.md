## 2. Technical Architecture & Verification

### 2.1 Polygonal Rasterizer (`src/features/polygon_rasterizer.py`)
- **`compute_polygon_mask_2d` & `apply_polygon_mask_to_array`:** Rasterizes arbitrary `Polygon` / `MultiPolygon` / `Feature` / `FeatureCollection` geometries onto the target `(H, W)` grid transform and sets exterior cells to `NaN`.
- **`validate_polygon_and_resolution`:** Computes geodesically scaled polygon area ($\text{km}^2$), fill ratio against the bounding box, and estimated valid onshore cells at the requested resolution (`50m`, `100m`, `250m`, `500m`), recommending coarser resolutions if cell count exceeds safe interactive memory thresholds.
- **`build_polygonal_feature_cube`:** Resamples source physical/structural/spectral GeoTIFFs onto the polygon-clipped grid, enforces `verify_no_raw_pixel_leakage`, writes `dataset.parquet` (containing strictly interior valid cells), `feature_stack.joblib`, `scanned_boundary.geojson`, and `feature_cube_meta.json`.

### 2.2 Backend API Endpoints (`scripts/dashboard_server.py`)
| Endpoint | Method | Purpose |
| :--- | :---: | :--- |
| `/api/models` | `GET` | Lists all active and archived model checkpoints with tree counts, PR-AUC, $\hat{c}$, domain, and resolution. |
| `/api/polygons` | `GET` | Lists predefined non-rectangular geological polygons and user-saved custom polygons (`data/polygons/`). |
| `/api/validate_polygon` | `POST` | Validates custom or predefined GeoJSON polygon at target resolution (`50m`–`500m`), returning `area_km2`, `est_valid_cells`, and `fill_ratio`. |
| `/api/train` | `POST` | Triggers background 7-pass training (fresh or warm-start from `base_run_id`) on a polygonal region at custom resolution and hyperparameters. |
| `/api/scan` | `POST` | Triggers fast inference-only scan (`--scan-only`) using a selected checkpoint over any polygonal region and resolution. |
| `/api/status` | `GET` | Returns real-time structured training/scan state (`pass_idx`, `progress_pct`, `phase`, `metrics`, `logs`). |
| `/api/performance` | `GET` | Returns real-time hardware telemetry (`system`, `cpu`, `memory`, `disks`, `scan_process`). |
