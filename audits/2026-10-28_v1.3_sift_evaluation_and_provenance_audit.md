## 2. Phase A — Evaluation Honesty (Leakage Findings)

### A1. In-Sample Fold Scoring in `blind_holdout.json` (L1) — **Critical**
- **Cause:** [`scripts/run_seven_pass_training.py:642-675`](file:///Volumes/Seagate%202/Geospatials/scripts/run_seven_pass_training.py#L642-L675) scores all 5 folds using `k4_ensemble.predict_proba_k4(X_va_f)`, where `k4_ensemble` was trained on `train_idx` (4 of the 5 folds are in-sample $\to$ PR-AUC $\approx 1.0$).
- **Remediation:** Fit fold-specific models during out-of-fold evaluation or report only held-out validation fold metrics honestly. Mark any head with $<5$ held-out positives as `"insufficient_data"` instead of defaulting to `0.50`.

### A2. OutMOGC Gate Fit on All Positives (L2) — **High**
- **Cause:** [`scripts/run_seven_pass_training.py:217-227`](file:///Volumes/Seagate%202/Geospatials/scripts/run_seven_pass_training.py#L217-L227) fits `OUTMOGCGate` on `X_all[pos_k_mask]` across the entire grid prior to train/val splitting.
- **Remediation:** Fit `OUTMOGCGate` strictly on `X_all[train_idx][y_k4[train_idx, k] == 1]`.

### A3. Exclusion Buffers & Propensity Use All Labels (L3) — **Medium**
- **Cause:** `positive_coords_k` and `explored_mask` include validation positives when building training exclusion radii and propensity models.
- **Remediation:** Build `positive_coords_k` for training strictly from `train_idx`.

### A4. Single Validation Fold Overloading (L4) — **High**
- **Cause:** The same `val_idx` sets ensemble blend weights, Elkan-Noto `c_hat`, conformal `q_hat`, and reported PR-AUC.
- **Remediation:** Split held-out blocks into disjoint calibration and evaluation blocks, or use full 5-fold cross-conformal / OOF predictions.

### A5. Maps/Ranking Use In-Sample XGBoost Scores (L5) — **Medium**
- **Cause:** Full-grid prospectivity maps blend OOF U-Net predictions with in-sample XGBoost predictions on the 80% training blocks.
- **Remediation:** Use OOF XGBoost predictions on training blocks for unbiased map generation.

### A6. Warm-Start Crossing Splits Without Fingerprint Check (L6) — **Medium**
- **Remediation:** Persist a dataset/split fingerprint (`dataset_hash`, `label_hash`, `fold_seed`, `block_size_px`, `feature_cols`) alongside checkpoints and refuse warm-start on mismatch.

## 3. Phase B — Model Output & Provenance Honesty

1. **B1. Feature-Name Mismatches (`alteration` fallback to `dem_slope` / `dilation_tendency_Td`):**
   - Lookups in [`scripts/run_seven_pass_training.py:481-485`](file:///Volumes/Seagate%202/Geospatials/scripts/run_seven_pass_training.py#L481-L485) fall back to `dem_slope` or band 0 when spectral alteration channels are absent.
2. **B2. Fabricated Site-Card Fallback Fields:**
   - [`emit_site_cards_json`](file:///Volumes/Seagate%202/Geospatials/src/outputs/prospectivity_map.py#L964-L1035) defaults missing sensor inputs to `al_oh="high"`, `kaolinite_alunite_doublet=True`, `aem_conductance_0_300m_S=15.0`, `sar_cloude_pottier_alpha_deg=45.0`, `moho_gravity_gradient_step_mGal_km=1.5`, `slip_tendency_Ts_mean=0.6`, and `sensor_source="EMIT_SWIR"`.
   - Remediation: Emit `null` and `"sensor_source": "not_available"` whenever an input physical layer is absent.
3. **B3. Heuristic Ore Labels vs. Calibrated Head Argmax:**
   - Persist `target_class`, per-head `L_k`, and `p_k` directly from the model's calibrated $K=4$ heads rather than post-hoc coordinate/threshold heuristics.
4. **B4. Make `/api/rerank` Read-Only:**
   - Return re-ranked GeoJSON in memory or write to `rerank_preview_*.gpkg` without overwriting registered run artifacts.
5. **B6. Summary Reporting Fixes:**
   - Log actual per-head `w_xgb_k` / `w_unet_k` instead of hardcoded `0.70 / 0.30`.
   - Log `q_hat_k4_list` instead of `np.quantile(c_hat_k4, 0.90)` under `conformal_q_hat_90`.
